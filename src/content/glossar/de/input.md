title: 'Input'

translationKey: input
---

Der Input (die Eingabe) ist das, was in eine [Funktion](/de/glossar/funktion) hineingegeben wird. Das können eine einzelne Zahl, ein Bild, ein Text oder viele zusammengehörige Werte gleichzeitig sein.

Bei einem Sprachmodell ist der Input keine zusammenhängende Textzeile, sondern eine Folge bereits vorhandener Textstücke — das, was bereits geschrieben steht, bevor das Modell überhaupt zu rechnen beginnt.

Ausführlicher erklärt in [Input und Output: Wie eine Funktion „denkt"](/de/bausteine/input-und-output).
