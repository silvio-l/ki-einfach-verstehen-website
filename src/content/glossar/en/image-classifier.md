An image classifier is a trained [model](/en/glossary/model) that takes an image as input and assigns it to one of several predefined categories — "cat" or "dog," for instance. The [training algorithm](/en/glossary/training-algorithm) sets the [parameters](/en/glossary/parameters) using thousands of already-categorized images; no human needs to decide in advance which image features actually distinguish the categories.

An image classifier works on exactly the same principle as a trained spam filter or a [language model](/en/glossary/language-model) — just with images instead of text or emails as [training data](/en/glossary/training-data).
