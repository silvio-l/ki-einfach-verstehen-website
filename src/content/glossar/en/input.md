title: 'Input'

The input is whatever gets fed into a [function](/en/glossary/function). It can be a single number, an image, a text, or many bundled values at once.

For a language model, the input at each prediction step is the text written so far. Given “The cat sits,” for example, the model sees only that existing part, not the word that will follow. Before the calculation, a [tokenizer](/en/glossary/tokenizer) follows fixed rules to divide the text into smaller pieces and assign them numbers.

Explained in more depth in [Input and Output: How a Function "Thinks"](/en/lessons/input-and-output).
