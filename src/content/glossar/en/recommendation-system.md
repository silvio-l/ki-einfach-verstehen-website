---
title: 'Recommendation system'
description: 'A system that selects possible content and ranks it by how relevant it might be to a person.'
translationKey: empfehlungssystem
---

A recommendation system selects possible content from a large pool and puts it in an order intended to be relevant to a person. It can combine several [algorithms](/en/glossary/algorithm) — fixed sequences of processing steps — with selection rules and trained [models](/en/glossary/model). The models might learn from past views or reactions which content is likely to be interesting.

When people talk about a platform's “algorithm,” they often mean this entire system — not one individual algorithm or model. A recommendation system can contain several stages: some select possible items, and others rank them by sorting the most promising items toward the top.

Explained in more depth in [Program, Algorithm, Model — What's the Difference?](/en/lessons/program-algorithm-model).
