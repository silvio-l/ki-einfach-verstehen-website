# KI einfach verstehen — Website

Source of the website at [ki-einfach-verstehen.de](https://ki-einfach-verstehen.de),
part of a larger project also producing a YouTube channel, an e-book, and
possibly an app around the same goal: making how AI actually works
understandable without a technical background.

Only this package (`packages/website`) is open source — the e-book, YouTube
scripts, and app content live in the same monorepo but are private and are
never mirrored here.

Built with [Astro](https://astro.build). Bilingual: German (`/de/`, default)
and English (`/en/`).

## Development

```
pnpm install
pnpm dev
```
